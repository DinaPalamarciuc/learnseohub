# LearnSEO Hub Keyword Map

Updated: May 28, 2026

## Goal

Map the Ahrefs keyword set to the current LearnSEO Hub pages, separate relevant queries from noise, and define the next pages with the highest SEO upside.

## Quick Take

The site already covers:

- AI SEO / GEO / AEO
- local SEO
- ecommerce SEO
- technical SEO
- free SEO tools
- prompts, downloads, and educational resources

The biggest gaps are:

- broad foundational SEO intent
- keyword research intent

- commercial service intent
- "free SEO tools" style comparison / roundup intent

## Ignore These Keywords

These should not drive content decisions for LearnSEO Hub:

- celebrity / person-name terms:
  - `park seo-joon`
  - `park seo joon`
  - `jeon jong-seo`
  - `jeon jong seo`
  - `seo ye-ji`
  - `seo ye ji`
  - `seo ji-hye`
  - `joe seo`

- spam / irrelevant domain terms:
  - `seo by highsoftware99.com`
  - `seo instant appear highsoftware99.com`
  - `2025 aelftech.com`
  - `seo agency interamplify`

These queries are not aligned with the site's brand, product, or audience.
